Employee Management System

A full-stack employee management application built using MEAN stack.

Tech Stack:
Frontend:
- Angular
- TypeScript
- Bootstrap

Backend:
- Node.js
- Express.js
- MongoDB

Features:
✓ User authentication
✓ JWT access and refresh tokens
✓ Role-based authorization
✓ Employee CRUD
✓ Search
✓ Pagination
✓ Sorting
